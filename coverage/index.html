The 90 rows of the Ledger Client Standard (86 Required, 4 Upcoming; cf-docs, last changed 2026-10-20) against the 2 Canton client SDKs in scope for the proof of concept. Generated 2026-11-20.

This is a desk survey, not a conformance result. Cells come from a static scan of each SDK's hand-written source for evidence of each capability, plus the SDK's own self-declared claims where they exist, plus hand review (hover a cell for the evidence and notes). "No evidence" means our scan found nothing. It may exist under another name. Maintainer corrections are very welcome. Live behavioural checks (the "Verified" state) come next, from the cross-SDK conformance runner.
  • Verified: Behaviour verified by a test run
  • Claimed: The SDK declares this row in its own machine-readable conformance registry
  • Evidence: Code or docs referencing this capability found in the SDK (heuristic, not a conformance result)
  • Partial: Hand review found building blocks only, not the whole row (hover for what is missing)
  • No evidence: Nothing found by the scan; may exist under other names. Corrections welcome
  • Out of scope: The library does not include this layer
  • Not assessed: Cannot be judged by static scan; needs manual review or a live test
